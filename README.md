# 🧠 Featured Projects

### 📡 Network Congestion Optimization

A research-oriented system designed to investigate network congestion in high-density environments where strong signal strength does not necessarily translate into good network performance.

The system combines **real network measurements, congestion detection, machine learning and traffic optimization** in a controlled Wi-Fi testbed.

**Tech:** `Python` `Flask` `React` `TypeScript` `Scikit-learn` `Wi-Fi` `iperf3` `SQLite`

🔗 **Repository:** [Network Congestion Optimization](https://github.com/vns-devtech/Network-Congestion-Optimization)

---

### 📄 Smart Resume Analyzer

An AI-powered web application that analyzes resumes, evaluates ATS compatibility, identifies missing skills and provides actionable feedback.

**Features:**

* Resume parsing
* ATS compatibility analysis
* Skill matching
* Missing skill detection
* AI-powered suggestions
* Resume scoring
* PDF report generation

**Tech:** `Python` `Flask` `JavaScript` `Chart.js` `PyPDF2` `python-docx` `ReportLab`

🚀 **Live Demo:** [Smart Resume Analyzer](https://smart-resume-analyzer-bez5.onrender.com/)

🔗 **Repository:** [Smart Resume Analyzer](https://github.com/vns-devtech/Smart-Resume-Analyzer)
